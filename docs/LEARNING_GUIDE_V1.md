# Learning Guide V1

## 目标

Learning Guide V1 将 UAV Studio 从“功能模块集合”补全为面向学习过程的实训平台。所有已登录角色共享同一条教学任务链：

```text
任务准备 → 装配确认 → 系统调试 → 故障诊断 → 起飞前检查 → 飞行验证 → 训练复盘
```

角色差异仅体现在使用目的：

- 学生：完成任务、形成诊断证据并获得改进建议；
- 教师：课堂示范、观察学习过程并查看学生复盘；
- 管理员：验收角色权限、任务链和证据可追溯性。

## 功能组成

### 1. 任务导航

所有业务页面顶部显示统一任务链、当前阶段、“现在要做”和完成标准。学生登录后默认进入“我的实训”，教师和管理员默认进入教师工作台。

### 2. 页面引导

“本页指引”抽屉统一提供：

- 本页目标；
- 当前任务；
- 建议步骤；
- 完成标准；
- 教学意义；
- 专业术语解释；
- 下一阶段入口。

系统调试页的指引会跟随内部子页面同步变化。飞控与传感器、遥控系统、动力系统、安全设置、起飞前检查分别提供独立的操作步骤、重点观察、常见误区、完成标准和术语解释。当前子页面写入 URL 的 `section` 参数，刷新、前进后退或从指引进入下一模块时仍能保持正确上下文。

### 3. 诊断工作单

系统调试页为所有角色提供五段式诊断工作单：

1. 故障现象；
2. 关键证据；
3. 原因判断；
4. 修复措施；
5. 验证结果。

工作单自动保存在当前账号与案例下。学生执行教师发布的课程任务时，完整工作单会写入 `TrainingEvent`，并随 `TrainingRun.result` 保存。未完成五项时不能提交课程诊断。

工作单遵循“按任务出现、默认折叠、提交时校验”：自由调试不显示；自主故障练习显示可选的紧凑入口；课程诊断任务显示必填状态。提交课程任务时若五项不完整，系统自动展开工作单并提示缺失内容。

### 4. 训练复盘

复盘页汇总：

- 任务状态、成绩、用时、提示与错误操作；
- 诊断工作单；
- 案例、规范操作和飞行分项成绩；
- Pre-Arm和飞行验证状态；
- 训练事件时间线；
- 基于当前记录生成的下一步练习建议。

学生可从已完成任务和飞行验证进入复盘；教师、管理员可从成绩册的 TrainingRun 详情进入学生复盘。

## 数据边界

- 有课程 `run_id` 的学生工作单：本地草稿 + `TrainingEvent` + `TrainingRun.result`；
- 自由训练或教师演示工作单：浏览器本地保存；
- 教师和管理员读取学生复盘：沿用现有班级、任务和 TrainingRun 权限，不扩大跨班级访问范围。

## 验证

- 前端单元测试覆盖任务阶段映射、角色入口、课程查询参数传递和证据链指引；
- 前端生产构建通过；
- 后端现有 121 项测试全部通过；
- 不新增数据库表，不改变现有训练记录兼容性。
