# UAV Studio V1 中文 UI / UX 冻结规格

## 1. 视觉定位

中文工程软件；浅色、克制、专业、适合课堂投影和长时间使用。

禁止：营销官网、赛博朋克、玻璃拟态、大面积渐变、大量无意义卡片。

## 2. 全局导航

顶部：
- UAV Studio V1
- 无人机装配
- 飞行实验
- 实验记录
- 当前飞机
- 当前仿真状态

所有用户可见文案使用中文；代码/API/enum 使用英文。

## 3. 无人机装配页

固定三栏：

```text
左：装配流程 276px | 中：3D 数字母机 | 右：上下文检查器 320px
```

左侧：7 步真实装配流程与当前组件选择。  
中间：机架/电机/ESC/电池/PDB/飞控/GNSS/载荷/桨/CG。  
右侧：整机或当前点击部件参数、装配检查。

V1 不做自由拖拽；使用“点击槽位 → 选择组件 → 安装”。

## 4. 飞行实验页

核心采用：

```text
左：实验控制 | 中：3D / 地图 / 分屏 | 右：实时状态
底：实时曲线
```

中央视图必须提供：
- **三维视图**
- **基础地图**
- **分屏**

三维视图：CG、M1~M4 推力箭头、重力、风、轨迹。  
基础地图：Home、当前 UAV、X/Y 轨迹、风向、比例尺。  
分屏：上 3D、下 Local Map 或左右分屏，优先保证 1366×768 可用。

## 5. 右侧状态

- 位置 X/Y/Z
- 速度 VX/VY/VZ
- 横滚/俯仰/偏航
- 角速度 P/Q/R
- 电池
- 估算功率
- M1~M4 输出
- M1~M4 推力

## 6. 底部曲线

Tabs：
- 飞行状态
- 姿态
- 电机
- 动力
- 轨迹
- 实验结果

保留最近 30~60 秒。

## 7. 实验记录

表格字段：时间、飞机、时长、最大高度、状态、操作。  
点击“查看/回放”进入 Replay。Replay 复用同一 TelemetryFrame 和主要可视化组件。

## 8. 中文术语冻结

- Assembly → 无人机装配
- Flight Lab → 飞行实验
- History → 实验记录
- Arm → 解锁
- Takeoff → 起飞
- Land → 降落
- Hovering → 悬停
- Attitude → 姿态
- Roll → 横滚
- Pitch → 俯仰
- Yaw → 偏航
- Thrust → 推力
- Center of Gravity → 重心
- Power Module / PDB → 电源模块
- Flight Controller → 飞控
