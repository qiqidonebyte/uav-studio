# UAV Studio V1 产品设计文档

版本：1.0 Frozen  
中文名称：**无人机数字设计与飞行验证平台**  
产品形态：**交互式无人机工程工作台**

## 1. 产品目标

让学生在一个统一的中文工作台里完成：

> 认识真实组件 → 按真实顺序装配 → 工程校核 → 看重心与受力 → 基础试飞 → 看地图轨迹 → 看数据 → Replay

它不是后台管理系统，不是飞行动画，也不是复杂环境仿真器。

## 2. 核心用户

- 高职无人机专业学生
- 无人机课程教师
- 实训室与竞赛团队

## 3. 核心工作区

### A. 无人机装配

用户按真实系统级顺序完成：

1. 机架
2. 动力系统：电机 + 电调
3. 供电系统：电池 + 电源模块/PDB
4. 飞控与导航：飞控 + GNSS/罗盘
5. 任务载荷
6. 螺旋桨
7. 装配检查

中央 3D 数字母机持续存在，显示组件位置、M1~M4、CW/CCW、CG。

### B. 工程计算与装配校核

至少输出：
- 总质量
- CG X/Y/Z
- 惯量估算
- 最大总推力
- 推重比
- 悬停油门
- 最大电流 / 功率
- 电池持续放电余量
- ESC 电流余量
- 理论续航
- 螺旋桨旋向检查
- 电压兼容检查

错误分为：
- **阻断错误**：不能进入飞行实验
- **警告**：允许试飞，但必须提示

### C. 基础飞行实验

SimpleSimulator 驱动，不允许前端动画伪造。

支持：
- 开始 / 暂停 / 复位
- 解锁
- 起飞到目标高度
- 悬停
- 降落
- 恒定风速 / 风向
- 简单位置保持

3D 中必须显示：
- 无人机位置和姿态
- CG
- M1~M4 推力箭头
- 重力箭头
- 风向/风场示意
- 飞行轨迹

### D. Local Flight Map

基础地图是 UAV Studio 的一部分，但不是复杂仿真环境。

显示：
- Home (0,0)
- 当前无人机位置
- X/Y 米制坐标
- 飞行轨迹
- 风向
- 比例尺
- 可选目标点

不做：
- 真实卫星底图
- 建筑三维环境
- 障碍物世界
- 复杂 Mission Planner

### E. 数据分析与 Replay

实时曲线：
- 高度 / 速度
- Roll / Pitch / Yaw
- M1~M4 输出与推力
- 功率 / 电池
- X/Y/Z 轨迹

Stop 后保存同一套 TelemetryFrame，History 中可 Replay。

## 4. 产品导航

中文导航固定：
- **无人机装配**
- **飞行实验**
- **实验记录**

## 5. V1 明确不做

- PX4 / SITL
- Gazebo
- ROS2
- AI / YOLO
- SLAM
- 强化学习
- 多机协同
- 固定翼 / VTOL
- 真实无人机接入
- CFD
- 用户权限
- 云端多用户
- 复杂地图

## 6. 最终产品验收主链

```text
无人机装配
→ 装配检查通过
→ 进入飞行实验
→ 解锁
→ 起飞 10m
→ 悬停
→ 设置 5m/s 侧风
→ 看到位置偏移、姿态变化、M1~M4 推力差异
→ Local Map 同步显示轨迹
→ 控制系统产生回稳趋势
→ 降落
→ 保存
→ History
→ Replay
```

该链没有跑通，不视为 V1 完成。
