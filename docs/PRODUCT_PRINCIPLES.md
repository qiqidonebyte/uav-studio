# UAV Studio 产品原则

## 核心原则

> 简单、有效地帮助学生学习，不过度设计。

所有后续功能、界面和教学流程都按这句话判断是否值得加入。

## 设计规则

1. 一个页面优先突出一个当前任务，学生应当立即知道现在要做什么。
2. 内容只在需要时出现；辅助信息默认折叠，不能长期挤占主要操作区域。
3. 能自动保存、自动带入和自动判断的内容，不要求学生重复操作。
4. 强制步骤只用于安全门禁、课程证据和必要的教学评价，并明确说明强制原因。
5. 每个指引都回答“做什么、怎么看、怎样算完成”，避免泛化说明。
6. 新功能必须直接改善学生学习、教师判断或课堂稳定性；不能说明价值时暂不增加。
7. 优先修复真实课堂中的迷茫、误操作和中断，再考虑增加新的功能模块。

## 诊断工作单的应用

- 自由调试：不显示工作单。
- 自主故障练习：显示紧凑入口，默认折叠，学生按需填写。
- 教师发布的课程诊断任务：显示紧凑入口，提交时校验“现象—证据—原因—修复—验证”五项。
- 工作单内容自动保存；未达到课程提交条件时，系统展开工作单并直接说明缺少内容。
