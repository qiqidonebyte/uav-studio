# UAV Studio V1 系统设置规格

## 用户

V1 只有一个本地管理员：

- 用户名：`admin`
- 初始密码：`123456`
- 密码以 PBKDF2-SHA256 哈希保存，不保存明文。
- 暂不做角色、注册、邮箱、OAuth、多人权限。

## 设置分区

### 账户与密码

修改 admin 密码；必须验证当前密码，新密码至少 6 位。

### 通用设置

- 公制单位。
- 小数位。
- 默认进入页面。
- 默认飞机 ID。
- 危险操作确认开关。

### 3D 显示

- 性能优先 / 平衡 / 高质量。
- 抗锯齿。
- 阴影质量。
- 环境反射。
- 网格 / 坐标轴 / CG / 推力 / 重力 / 风 / 轨迹显示。
- 轨迹点数。
- 默认相机。

设置直接驱动 `DroneScene`，不是仅保存表单。

### 飞行实验

- 默认高度。
- 默认风速 / 风向。
- 默认 3D / Map / Split 视图。
- 实时图表时间窗口。
- 是否自动创建仿真。
- 是否自动连接遥测。

安全状态机不允许由设置绕过：

`开始 → 解锁 → 起飞 → 降落`

系统不存在自动解锁、自动起飞选项。
