# UAV Studio V1 组件库规格

## 产品目的

组件库不是独立的素材页面，而是 UAV Studio 的工程组件数据库。装配页和组件库使用同一份 `components` 数据。

## V1 一级能力

- 九类组件浏览：机架、电机、电调、螺旋桨、电池、电源模块、飞控、GNSS、载荷。
- 名称 / ID 搜索与分类筛选。
- 组件卡：缩略图、名称、类型、质量、3D状态、标签。
- 组件详情：基本信息、工程参数、性能数据、3D资产、适配关系。
- Three.js 单组件 3D 预览。
- 复制现有组件为自定义组件。
- 编辑组件名称、质量、工程参数、备注、标签。
- 后端在保存前验证工程参数契约，非法参数不得落库。
- 组件修改后装配页可刷新使用同一组件。

## 适配关系

适配不是手写静态文案，优先从工程数据推导：

- 电机 ↔ 螺旋桨：来自性能曲线 `propeller_id`。
- 电机 ↔ 电池：来自性能曲线电压。
- 电池 ↔ ESC：标称电压处于 ESC 电压范围。
- ESC ↔ 电机：性能曲线最大电流不超过 ESC 能力。
- Frame / FC / GNSS / Payload：基于 V1 标准安装槽关系。

## 数据安全

`_visual` 和 `_library` 是持久化保留字段，不属于工程计算输入。组件编辑不得直接覆盖 `_visual`。
