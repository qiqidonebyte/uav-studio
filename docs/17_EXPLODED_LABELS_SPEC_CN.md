# 爆炸视图组件标签规格

## 目标

爆炸视图需要直接告诉学生“这个 3D 部件是什么”，但不能让标签遮住飞机或互相遮挡。

## 显示策略

- 只在爆炸进度达到 72% 后显示，避免展开动画阶段视觉拥挤。
- 一种组件只显示一个标签；电机、电调、螺旋桨显示为 `×4`，不重复堆 12 个标签。
- 标签读取真实 `Component.name`，不写死型号。
- 未安装 Ghost 不显示名称标签，减少噪声。
- 左右双列贴近场景边缘布置，中央 3D 飞机保持干净。
- 标签根据组件投影高度排序，再进行碰撞消解，保证同列不重叠。
- 标签最大 164×26 px，名称超长时省略号截断。
- 选中组件使用蓝色描边；工程问题使用红色描边。

## 标签示例

`电机 ×4  EduMotor-5010-360KV`

`电池  EduBattery-6S-10000`

## 其他 UI

原来的 `GLB 教学模型` 角标完全删除。资产加载失败仍保留错误面板。
