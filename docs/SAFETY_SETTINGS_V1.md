# 安全设置 V1

## 页面定位

本页不是 QGroundControl 参数页的复制品，而是把 PX4 中与高职无人机装调检修课程最相关的安全参数组织为教学任务。

流程：

`读取参数 -> 理解策略 -> 修改草稿 -> 自动检查 -> 写入 PX4 -> Pre-Arm 验证`

## 教学分组

### 1. 遥控 / 数据链路失联
学生需要理解“何时判定失联”和“失联后做什么”是两个独立概念。

### 2. 低电量
学生需要保证阈值顺序正确：

`Low > Critical > Emergency`

并理解告警、返航、降落是不同安全阶段。

### 3. RTL / Geofence
页面主动检查：

`RTL_RETURN_ALT < GF_MAX_VER_DIST`

当垂直围栏启用时，避免返航爬升高度与围栏发生明显冲突。

### 4. Arming
把“允许解锁”“GPS要求”“解锁后未起飞自动上锁”“落地后自动上锁”集中到一个教学区域。

## 真实 PX4 模式

当前版本复用 PX4 Bridge V1 已有的参数接口：

- `GET /api/px4/parameters/{name}`
- `PUT /api/px4/parameters/{name}`
- `POST /api/px4/prearm-check`

为了避免多个 HTTP 请求并发争用同一 pymavlink 通道，安全页读取参数时采用顺序读取。

参数编辑采用 staged editing：

1. 读取真实参数。
2. 在浏览器本地修改。
3. 自动进行策略检查。
4. 统一点击“应用到 PX4”。
5. PX4 返回 PARAM_VALUE 后更新基线。

飞机处于 Armed 状态时，安全页禁止写入参数。

## 教学模拟模式

未连接 PX4 时：
- 标准场景加载教学推荐配置。
- Failsafe 异常场景加载故障配置。
- 修复并应用后恢复教学评分。
- 所有操作都会明确标记为教学模拟，不冒充真实 PX4 写入。
